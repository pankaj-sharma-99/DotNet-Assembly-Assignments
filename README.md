# .NET Assembly Assignments

This repository contains solutions and documentation for three assignments related to C# class libraries and .NET assemblies.

## Assignment 1: Tax Library

**Folder:** `Question1-TaxLibrary`

### Contents
- `TaxCalculator.cs` — Calculates tax under illustrative old and new regimes.
- `Program.cs` — Console application that uses the tax calculator.
- `README.md` — Build instructions and advantages of class libraries.

### Concepts Covered
- Creating reusable class libraries
- Generating DLL files
- Referencing a library from a console application
- Code reusability and maintainability

## Assignment 2: University Library

**Folder:** `Question2-UniversityLibrary`

### Contents
- `Student.cs` — Defines the Student class.
- `StudentApp1.cs` — First client application.
- `StudentApp2.cs` — Second client application.
- `README.md` — Instructions for strong-name signing and GAC installation.

### Concepts Covered
- Strong-named assemblies
- Generating a strong-name key
- Installing assemblies into the Global Assembly Cache (GAC)
- Sharing a library between applications

## Assignment 3: Salary Library Versioning

**Folder:** `Question3-SalaryLibrary`

### Contents
- `Version1/SalaryCalculator.cs` — Basic salary calculation.
- `Version1/AssemblyInfo.cs` — Version 1.0.0.0 metadata.
- `Version2/SalaryCalculator.cs` — Basic salary, allowances, and total salary.
- `Version2/AssemblyInfo.cs` — Version 2.0.0.0 metadata.
- `ClientApp1/Program.cs` — Client for Version 1.0.
- `ClientApp2/Program.cs` — Client for Version 2.0.
- `README.md` — Build instructions and versioning concepts.

### Concepts Covered
- Assembly versioning
- Maintaining different library versions
- Referencing DLLs from client applications
- Backward compatibility considerations

## Technologies Used
- C#
- .NET Framework
- Class Libraries
- DLL Assemblies
- Console Applications

## How to Use This Repository

1. Open the folder for the required assignment.
2. Read its `README.md`.
3. Follow the documented build and execution commands.
4. Use a suitable Windows .NET Framework developer environment to compile and run the examples.

## Important Note

This repository contains C# source code and build instructions. Compiled DLLs and executable files must be generated by running the build commands in the appropriate environment.

The examples are educational demonstrations. The tax calculations use illustrative slabs and are not a complete implementation of official tax rules.
